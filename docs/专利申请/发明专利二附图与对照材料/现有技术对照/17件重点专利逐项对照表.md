## 1. 本方案待保护特征编码

| 编码 | 技术特征 |
| --- | --- |
| F1 | 接收同一周期周扫设备的第一、第二成像通道异步检测记录，并映射到统一环形全景坐标。 |
| F2 | 根据校正后的全景纵坐标和设备纵向有效视场角确定相对高度角；当前工程参数为 `FOVv=26.88°`，该参数仅作坐标归一化依据。 |
| F3 | 把候选时间关系区分为跨通道近时配对、跨通道相位延迟配对、跨扫描周期重访三类。 |
| F4 | 对跨圈重访计算时间差相对于扫描周期整数倍的周期残差 `|Δt-nT|`，而不是使用一个无类型的大时间窗。 |
| F5 | 在计算候选代价前，禁止来源帧标识相同的不同检测记录被归入同一事件，即同源帧互斥。 |
| F6 | 在关系类型门控之后，联合使用环形方位差、高度角差、周期残差、目标框形态、局部外观和类别兼容性进行排他选择。 |
| F7 | 关联成功时沿用稳定事件标识，并更新来源集合、命中次数、代表类别、置信度、代表图像和生命周期；关联失败时建立新事件。 |
| F8 | 分层保存用于关联的原始方位和用于界面校准的显示方位；北向显示偏置不回写关联数据。 |
| F9 | 全景背景和融合事件共用方位变换以及高度角—半径变换；极坐标半径表示视线高度角而非物理距离或目标物理高度。 |

## 3. 最接近的组合路径与风险判断

### 组合路径A：周扫系统 + 跨圈处理 + 通用事件融合 + 环形显示

`CN117495914B + CN113741505B + CN111783905A（或CN110781949B）+ US8355536B2`

该组合能够拼出“双通道/多波段周扫、跨圈同目标、融合生命周期、方位—角度和俯仰—半径显示”的大部分上位功能，是当前最需要防范的创造性组合。相对该组合，建议保留的最小区别链为：

1. 来源帧标识相同构成不可被代价覆盖的禁止关联条件；
2. 对允许关联的记录，区分跨通道近时、跨通道相位延迟和跨整数圈重访；
3. 仅跨圈关系使用或重点使用 `|Δt-nT|` 周期残差；
4. 上述规则产生稳定事件后，关联原始方位保持不变；
5. 北向偏置只同步作用于全景背景和事件显示；
6. 背景和事件使用同一高度角—半径标定，半径不表示距离。

### 组合路径B：视场角标定 + 光电角度关联 + 全景目标覆盖

`CN113850905B + CN111693051A + US9778351B1`

该组合能够覆盖“由视场角求像素角度、按方位/俯仰关联、把异步目标映射到全景”。本方案不应把 `26.88°`、针孔公式或全景覆盖作为核心；应证明相对高度角用于三类扫描相位候选的统一空间证据，并进一步驱动背景/事件共同投影。

### 组合路径C：全景多特征匹配 + 异步航迹管理 + 冲突处理

`CN115170620A + CN110781949B + CN114966662A`

该组合能够覆盖多特征代价、异步生命周期和一对一/一对多冲突。主要抗辩点不应是更换匹配算法，而应是输入数据具有同一周期周扫设备的来源帧与相位结构，因而先实施同源帧硬互斥，再按三类时间关系建立候选；这是普通连续视频或通用航迹融合没有直接给出的处理次序和不变量。

## 4. 对独立权利要求的直接约束

以下内容已被现有技术直接或高度相似地公开，不建议单独作为独立权利要求的创造性中心：

- 双光/多波段360°周扫和全景目标标注；
- 由视场角、图像尺寸和像素位置计算方位角或高度角；
- 一般的多特征代价、匈牙利匹配或点迹—航迹关联；
- 匹配成功更新、匹配失败新建以及生命周期管理；
- 360°边界处保持ID；
- 方位映射极坐标角度、俯仰映射极坐标半径；
- 用安装角、姿态或北向偏置校准显示。

独立方法权利要求宜把F3、F4、F5作为关联侧骨架，把F7作为中间数据结果，并以F8、F9形成显示侧闭环；F1和F2说明该骨架只针对特定周扫双成像数据。若因审查意见需要拆分，优先保留以下两组相互依赖的区别：

- 关联组：`F1 + F3 + F4 + F5 + F6 + F7`；
- 坐标显示组：`F2 + F7 + F8 + F9`，并说明稳定事件是显示组输入，而非任意目标点。

## 6. 初检结论

截至2026-09-03，本轮17件重点文献中未发现一篇单独完整公开F1～F9的闭环组合，但多个单项特征已经存在直接公开，且“周扫系统文献 + 通用融合文献 + 环形显示文献”的组合动机客观存在。因此当前风险结论为：

- 单项新颖性依赖：弱；
- 组合新颖性初判：尚可；
- 创造性组合风险：中等；
- 最值得保留的抗辩中心：同源帧硬互斥、三类扫描相位关系及整数圈周期残差的顺序化关联机制，与稳定事件的原始/显示坐标分层和背景/事件共同投影形成的可验证闭环。

正式递交前应由专利代理师以权利要求1的最终文本重新检索，并逐条确认各对比文件的法律状态、优先权日、同族文本和原文翻译。
