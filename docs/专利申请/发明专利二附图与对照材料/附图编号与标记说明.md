## 5. 主要符号

| 符号 | 含义 |
| --- | --- |
| `Wl`、`Hl` | 旋转前线阵输出帧的有效`Width`（Sensor空间线轴）和`Height`（累计扫描行数） |
| `Wp`、`Hp` | 环形全景图像的有效宽度和高度；当前实施例为65536和4096像素，其中`Hp`来自旋转后的线阵有效`Width` |
| `panoX`、`panoY` | 全景目标坐标；当前处理链中`panoX`来自累计扫描行/转台方位，`panoY`来自反向的Sensor空间线坐标 |
| `v`、`vu` | 目标纵坐标及完成校正后的目标纵坐标 |
| `cy` | 主点纵坐标；理想模型示例取2047.5像素 |
| `FOVv` | 线阵Sensor空间轴对应的垂直视场角；当前确认为26.88°，仍待规格依据及其与完整`Width Max`或有效ROI的关系 |
| `fy` | 纵向像素焦距，理想模型下为 `Hp/[2tan(FOVv/2)]` |
| `βrel` | 相对于设备光轴的视线高度角，不是目标物理高度 |
| `θraw` | 用于事件关联和日志记录的原始方位 |
| `δN` | 只用于界面校准的北向显示偏置 |
| `θdisplay` | 经过北向偏置变换后的显示方位 |
| `ρ` | 由高度角映射得到的极坐标显示半径，不表示物理距离 |
| `T` | 扫描周期 |
| `Δt` | 两次检测记录之间的时间差 |
| `n` | 最接近 `Δt/T` 的不小于1的整数圈数 |
| `εT` | 跨圈周期残差 `|Δt-nT|` |

## 6. 工程测角流程标记

| 标记 | 名称或作用 |
| --- | --- |
| A1 | 检测框中心和当前全景坐标记录 |
| A2 | 旋转、镜像、去畸变前后的坐标链及双通道配准 |
| A3 | 线阵空间轴射线模型和畸变校正 |
| A4 | 相对于相机光轴的视线高度角 |
| B1 | 只有总视场角时的理想模型估算 |
| B2 | 结合外参和设备姿态取得绝对视线角 |
| C1 | FOV模型估算级输出 |
| C2 | 标定测角级输出 |
| C3 | 还需距离和设备位置才能得到的物理高度/海拔 |
