## 3. 统一制图约定

- 附图采用黑线、白底、无颜色依赖的SVG矢量格式，便于后续修改和导出PDF。
- 正式附图使用“图1”至“图10”；两幅“核对图”仅供工程确认，不计入正式图号。
- 模块和步骤使用三位或四位附图标记，具体含义见《附图编号与标记说明》；流程步骤使用 `S101` 等编号。
- 图中文字用于当前撰写核对。正式递交版本可按代理师要求精简文字，只保留框图名称、标记和必要公式。
- `FOVv=26.88°`、`Hp=4096`及由此得到的约 `±13.44°` 为当前方案参数。海康手册和当前软件坐标变换已经确认：`Hp`来自线阵Sensor的有效`Width`，旋转后成为`panoY`；仍待确认26.88°覆盖完整`Width Max`还是当前ROI，并标定主点、畸变、滚转、光轴绝对俯仰和双通道偏移。
- 图10只引用已保存日志中可复核的样本；换算高度角是理想针孔模型计算值，不表述为经纬仪标定真值。

## 4. 重新生成附图

在本目录执行：

```bash
python3 附图源文件/生成专利附图.py
```

脚本会覆盖“专利附图”目录中同名的12个SVG文件，不处理上级目录中的任何其他文档。需要修改文字、参数或版式时，应先修改生成脚本再重新生成，以保持图件一致。

## 5. 后续需要人工补入的内容

本轮已把不依赖新增设备操作的材料先行补齐。以下内容需要用户或现场人员提供后才能把附图从“底稿”固化为申请稿：

1. 26.88°视场角的规格书、厂家说明或原始标定记录，并确认其覆盖完整`Width Max`还是当前`Width+Offset X`有效ROI；
2. 相机主点、畸变、滚转、光轴俯仰和双通道偏移标定结果；
3. 至少两个转速下的真实扫描周期与跨通道相位统计；
4. 北向偏置前后背景控制点和事件标记的截图或坐标误差记录；
5. 发明人、申请人、首次公开/销售/演示日期等法律和主体信息。

取得上述材料后，应同步更新图9、图10、技术交底书实施例参数和对比试验表，不应只修改附图中的数值。
